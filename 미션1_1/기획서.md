# [기획서] 영화 티어리스트 웹페이지 기획안

## 1. 프로젝트 개요
- 목적: 사용자가 직접 영화를 S, A, B, C, D 등급별로 분류하고 관리할 수 있는 인터랙티브 웹페이지 제작
- 대상 사용자: 영화를 사랑하고 자신만의 순위를 정리하고 싶어 하는 일반 사용자

## 2. 주요 기능 요구사항
- 등급별 레이아웃: S, A, B, C, D 5단계의 티어 보드 구성
- 영화 추가 및 관리: 원하는 영화 제목을 직접 입력하여 추가하거나, 예시 영화를 자동으로 불러오는 기능
- 직관적 인터페이스: 드래그 앤 드롭 또는 버튼 조작을 통해 영화 순위를 유연하게 조정 가능
- 단일 파일 구현: 별도의 외부 서버나 복잡한 설치 없이, 하나의 HTML 파일(`HTML + CSS + JavaScript`) 내에서 모든 기능이 즉시 브라우저로 실행되도록 함
