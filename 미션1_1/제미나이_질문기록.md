# 영화 티어리스트 웹페이지 기획서 (기획서.md)

## 1\. 누가 쓰나 (Target Audience)

* **개인 사용자**: 자신만의 영화 순위 및 티어리스트를 쉽고 빠르게 정리하고 보관하고 싶은 사람 (로그인/회원가입 없음)

## 2\. 무엇을 하려고 (Goal \& Purpose)

* 영화 제목을 입력하여 티어리스트에 추가하고, S / A / B / C / D 등급 칸에 드래그 앤 드롭으로 배치하여 나만의 영화 티어표를 완성하는 웹페이지 제작

## 3\. 화면과 동작 (UI \& Behavior)

* **입력 영역**: 영화 제목 입력창 및 '추가' 버튼
* **미배치 항목 영역**: 생성된 영화 카드가 최초로 위치하는 영역
* **티어 영역 (S, A, B, C, D)**:

  * 각 등급별 구획 구분
  * 드래그 앤 드롭(Drag \& Drop)을 통해 영화 카드를 각 등급 칸으로 이동 가능
* **삭제 및 수정**: 잘못 추가한 영화 카드는 클릭 또는 드래그하여 삭제 가능

## 4\. 필요한 자료 (Requirements \& Assets)

* **기술 스택**: HTML, CSS, JavaScript (단일 페이지 웹 앱)
* **드래그 앤 드롭 라이브러리/기능**: HTML5 Drag and Drop API 또는 드래그 지원 스크립트
* **외부 API/이미지 라이브러리**: 필요 없음 (순수 텍스트 카드로 구성)

## 5\. 완성 기준 (Acceptance Criteria)

1. 영화 제목 입력 후 추가 시 미배치 영역에 텍스트 카드가 생성된다.
2. 영화 카드를 S, A, B, C, D 등급 영역으로 유연하게 드래그하여 배치/이동할 수 있다.
3. 복잡한 설정 없이 브라우저에서 바로 실행되고 직관적인 화면을 제공한다.
이 기획서대로 HTML·CSS·JavaScript가 모두 들어 있는 HTML 파일 하나를 만들어 줘.

외부 파일이나 서버 없이 브라우저에서 바로 열리게 하고, 화면 문구는 한국어로 써 줘.

완성된 코드 전체를 코드 블록에 담아 .html 파일 형태로 제공해 줘.

작성해주신 기획서에 맞춰, 별도의 서버나 외부 설치 없이 브라우저에서 바로 열 수 있는 단일 파일(index.html) 형태의 영화 티어리스트 웹 애플리케이션을 생성하겠습니다.

드래그 앤 드롭, 카드 삭제, 엔터키 입력 지원, 모바일 터치 대응 및 세련된 다크 모드 디자인을 적용했습니다.
