 나만의 유용한 링크 모음 - 최종 기획서

## 1. 개요 및 목적
- 페이지 이름: 나만의 유용한 링크 모음
- 목적: 자주 사용하는 주요 웹사이트(포털, 검색엔진, 개발 플랫폼, 학습 문서 등)에 빠르고 편리하게 접근할 수 있도록 정리한 링크 모음 페이지.
- 대상 사용자: 유용한 웹사이트 링크를 한곳에서 모아보고 싶은 일반 사용자 및 학습자.

## 2. 화면 구성 및 주요 기능
- 상단 헤더: 페이지 제목과 간단한 안내 문구 배치.
- 링크 카드 레이아웃: 
  - 각 웹사이트를 카드 형태(`card`)로 구분하여 시각적 가독성 향상.
  - 네이버, 구글, 깃허브, MDN 웹 문서 카드 총 4개 구성 (사용자 피드백 반영하여 네이버 카드 추가).
- 인터랙션 및 동작:
  - '바로가기' 버튼 클릭 시 외부 웹사이트가 **새 탭(`target="_blank"`)**으로 열려 기존 페이지 이탈 방지.
  - 반응형 디자인(Media Query)을 적용하여 스마트폰 등 모바일 화면에서도 좌우 여백과 콘텐츠가 유연하게 정렬됨.

## 3. 추가 기능 (향후 개선 사항)
- 사용자 로그인 및 개인별 즐겨찾기 저장 기능
- 다크 모드(Dark Mode) 테마 지원
- 실시간 검색 기능 추가

## 4. 비목표 (이번 버전에서 제외하는 것)
- 회원가입 및 데이터베이스 연동 기능 제외
- 실시간 채팅 및 AI 챗봇 기능 제외
- 서버 기반의 사용자별 맞춤 설정 기능 제외

## 5. 검증 방법
- 웹 브라우저(크롬 등)에서 최종 HTML 파일을 열어 각 카드의 '바로가기' 버튼이 새 탭으로 정상 연결되는지 확인.
- 브라우저 창 크기를 스마트폰 화면 크기로 줄여 모바일 반응형 레이아웃 및 여백이 깨지지 않고 자연스럽게 표시되는지 검증.
