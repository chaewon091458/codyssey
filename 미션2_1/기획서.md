# HTML 페이지 기획서

## 1. 기본 항목
- 대상 사용자: 프로그래밍을 처음 배우는 초보 학습자 및 주변 지인들
- 사용 목적: 평소 자주 참고하는 유용한 웹사이트와 학습 링크를 한곳에 모아 쉽고 빠르게 접근하기 위함
- 화면 구성과 동작: 
  - 상단: 페이지 제목("나만의 유용한 링크 모음")과 간단한 소개 문구
  - 본문: 3개 이상의 카드 형태 구역(사이트 이름, 설명, 바로가기 버튼)
  - 동작: '바로가기' 버튼을 클릭하면 해당 웹사이트가 새 탭으로 열림
- 필요한 자료: 인터넷상에 있는 공개된 웹사이트 URL 주소 및 무료 아이콘 이미지 주소(https://...)
- 완료 기준: 
  - 별도의 서버나 로그인 없이 index.html 파일을 더블클릭해 브라우저로 열었을 때 화면이 깨지지 않고 나타난다.
  - 화면에 있는 링크 버튼을 누르면 지정된 웹사이트로 정확히 이동한다.

## 2. 기능 목록
- 필수 기능: 유용한 사이트 목록 카드 표시, 링크 클릭 시 이동 기능
- 추가 기능: 화면 전체를 깔끔하게 정렬해 주는 기본 CSS 스타일 적용

## 3. 한계 및 비목표 (3가지)
1. 사용자가 직접 사이트를 추가하거나 삭제하는 동적 데이터 저장 기능은 구현하지 않는다.
2. 회원가입 및 로그인 기능은 구현하지 않는다.
3. 백엔드 서버나 외부 데이터베이스를 연동하지 않고 순수 정적 파일로만 구성한다.

## 4. 검증 방법 (1가지)
- 검증 절차: 페이지에 배치된 링크 버튼들을 모두 하나씩 직접 클릭하여, 오류 페이지(404 등) 없이 의도한 웹사이트로 정확히 연결되는지 확인한다.

## 5. 사용한 AI 서비스와 모델 이름
- AI 서비스 및 모델: Google Gemini
