# 영화 티어리스트 웹페이지 기획서

## 1. 기본 정보
- 사용한 AI 서비스 / 모델 이름: Gemini / Gemini 1.5 Pro

---

## 2. 기본 항목

### 2.1 대상 사용자
* 특정 영화들을 등급별로 구분하여 한눈에 정리하고 싶은 사용자.
* 로그인이나 별도 프로그램 설치 없이 웹 브라우저로 단일 HTML 파일을 열어 사용하고자 하는 사람.

### 2.2 사용 목적
* 선호하는 영화 제목을 입력하여 카드로 만든 뒤, S / A / B / C 등급으로 구분하여 한눈에 볼 수 있도록 시각적으로 정리합니다.

### 2.3 화면 구성과 동작
* 상단 헤더 및 입력 구역:
  - 페이지 제목("영화 티어리스트")이 위치합니다.
  - 영화 제목을 입력할 수 있는 텍스트 입력창과 [추가] 버튼이 있습니다.
* 티어 구역 (Tier List):
  - S, A, B, C 총 4단계의 등급 영역이 세로로 나열됩니다.
  - 각 등급 구역은 명확한 라벨과 구분선/색상으로 나뉩니다.
* 미분류 구역 (Unranked Area):
  - 입력창에 영화 제목을 입력하고 [추가] 버튼을 누르면 이 영역에 새로운 영화 카드가 생성됩니다.
* 화면 동작 (인터랙션):
  - 카드 생성: 입력창에 영화 제목을 작성하고 [추가] 버튼을 누르면 '미분류 영역'에 해당 영화 카드가 나타납니다.
  - 카드 배치/이동: 미분류 영역에 생성된 영화 카드를 클릭 또는 드래그하여 S, A, B, C 등급 구역 및 미분류 영역 간에 자유롭게 배치할 수 있습니다.
  - 카드 삭제: 각 영화 카드에 있는 삭제(X) 버튼을 누르면 화면에서 제거됩니다.

### 2.4 필요한 자료
* 단일 HTML 파일 구현을 위한 기본 HTML5/CSS3/JavaScript 라이브러리 코드 (외부 이미지 서버나 별도 API 연동 없이 텍스트 기반 카드 구조로 구현).

### 2.5 완료 기준
* 입력창에 영화 제목을 입력하고 [추가] 버튼을 누르면 '미분류 영역'에 영화 카드가 정상적으로 생성되어 표시됩니다.
* 카드를 S, A, B, C 등급 구역 및 미분류 영역으로 이동 및 배치할 수 있으며, 삭제(X) 버튼을 누르면 카드가 지워집니다.
* 별도의 서버 설치, DB, 로그인 없이 단일 HTML 파일 형태(.html)로 웹 브라우저에서 바로 열리고 동작합니다.

## 3. 기능 분류

### 3.1 필수 기능
1. 텍스트 입력 및 [추가] 버튼을 통한 영화 카드 생성 기능
2. S, A, B, C 등급 구역 및 미분류 구역 간 카드 이동/배치 기능
3. 영화 카드 개별 삭제(X) 기능

### 3.2 추가 기능
1. 새로고침 후에도 등록한 영화 및 배치 상태가 유지되도록 브라우저 내 LocalStorage 연동 기능
2. 전체 초기화 버튼 제공 기능

---

## 4. 한계 및 비목표 (3가지)
1. 영화 포스터 이미지를 외부에서 자동으로 가져오는 기능은 구현하지 않으며 텍스트 기반 카드로 대체합니다.
2. 회원가입, 로그인 및 사용자 계정 관리 기능은 이번 구현 범위에서 제외합니다.
3. 외부 서버 및 데이터베이스(DB)를 활용한 기기 간 실시간 데이터 동기화 기능은 제공하지 않습니다.

---

## 5. 검증 방법 (1가지)
* 검증 내용: 영화 제목 입력 후 [추가] 버튼 클릭, 등급 간 이동, 삭제 동작이 정확히 작동하는지 확인.
* 비교 대상 및 절차: 단일 HTML 파일을 웹 브라우저(Chrome)로 연 뒤, '영화 제목 입력 ➔ 추가 ➔ S등급으로 이동 ➔ 삭제' 순서로 실행하여 기획한 인터랙션대로 오류 없이 화면에 즉각 반영되는지 직접 실행하여 검증합니다.
