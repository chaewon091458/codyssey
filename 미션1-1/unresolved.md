# 미해결 과제 (Unresolved Issues)

## 1. 현재 상태
- 현재 프롬프트 설계 및 검증 테스트 기준, **치명적인 미해결 과제는 없습니다.**

## 2. 확인 근거
- **출력 형식 일관성:** Few-shot 예시 적용 및 출력 규격(교정본 → 주요 수정 내역 → 더 자연스러운 표현 제안 → 선생님 한마디) 고정 후, 의도한 구조대로 안정적으로 출력됨을 확인했습니다.
- **환각(Hallucination) 검증:** 원문에 없는 정보(국적, 거주 기간, 식당·메뉴 등)나 불확실한 사실·잘못된 전제를 묻는 5개 검증 항목 모두 임의로 지어내지 않고 확인 필요로 안내함을 검증했습니다.

## 3. 향후 보완 가능 사항 (참고)
- 현재 단계에서는 요구사항을 모두 충족했으나, 추후 다양한 학습자 급수(초급~고급)와 긴 장문 데이터가 추가될 경우 수준별 교정 강도 세분화 테스트를 이어갈 예정입니다.
