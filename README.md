> AI 활용 웹 페이지 기획 및 개발 프로젝트  
> AI 도구(Gemini, ChatGPT)를 활용하여 기획부터 웹 초안 구현까지 진행한 기록 및 결과물 저장소입니다.

1. 프로젝트 소개 (Overview)
- 프로젝트명: Codyssey (코드 오디세이)
- 목적: 
  - 생성형 AI를 활용한 아이디어 기획 및 웹 페이지 초안 작성
  - 프롬프트 기록과 개발 과정을 체계적으로 정리하고 관리

2. 파일 및 폴더 구조 (Directory Structure)

```text
codyssey/
├── README.md               # 프로젝트 안내서 (현재 파일)
├── 기획서.md               # 프로젝트 전체 기획 및 방향성 정리
├── 미션1_기록.md           # 미션 1 수행 과정 및 결과 기록

├── 제미나이_질문기록.md     # Gemini 활용 프롬프트 및 대화 기록

기획서.md: 프로젝트의 기본 배경, 목표, 주요 기능 요구사항이 정의되어 있습니다.

영화_A_초안.html / 영화_B_초안.html: 기획안을 바탕으로 HTML/CSS/JS로 제작한 웹 시안입니다.
제미나이_질문기록.md & 챗GPT_질문기록.md: 문제 해결 및 코드 생성을 위해 사용한 AI 프롬프트 이력입니다.
